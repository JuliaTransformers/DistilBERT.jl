DistilBERT.jl

A pure Julia implementation of the DistilBERT model, built with Flux.jl.

Quick Start

using DistilBERT, Flux

model = load_model("models/distilbert-base-uncased")   # dir or HF Hub ID
tokenizer = WordPieceTokenizer("models/distilbert-base-uncased/vocab.txt")
Flux.testmode!(model)                                  # disable dropout

output = predict(model, tokenizer, "Hello world!")     # (dim, seq_len, 1)
embedding = embed(model, tokenizer, "Hello world!"; pooling=MeanPooling)

Return values live on the same device as the model parameters.

Model & Config

DistilBERT.DistilBertConfig — Type
DistilBertConfig

Configuration for the DistilBERT model.

Fields

  • vocab_size::Int: Vocabulary size (default: 30522)
  • dim::Int: Dimensionality of the encoder layers and the pooler layer (default: 768)
  • n_layers::Int: Number of hidden layers in the Transformer encoder (default: 6)
  • n_heads::Int: Number of attention heads for each attention layer in the Transformer encoder (default: 12)
  • hidden_dim::Int: Dimensionality of the "intermediate" (i.e., feed-forward) layer in the Transformer encoder (default: 3072)
  • dropout::Float32: The dropout probabilitiy for all fully connected layers in the embeddings, encoder, and pooler (default: 0.1)
  • max_position_embeddings::Int: The maximum sequence length that this model might ever be used with (default: 512)
  • initializer_range::Float32: The standard deviation of the truncatednormalinitializer for initializing all weight matrices (default: 0.02)
  • qa_dropout::Float32: Dropout probability for the QA head (default: 0.1)
  • seq_classif_dropout::Float32: Dropout probability for the sequence classification head (default: 0.2)
source
DistilBERT.DistilBertModel — Type
DistilBertModel

The bare DistilBERT Model transformer outputting raw hidden-states without any specific head on top.

Fields

  • config::DistilBertConfig: Model configuration.
  • embeddings::Embeddings: Word/position embeddings and layer norm.
  • transformer::NTuple{N,TransformerBlock}: The encoder blocks. Storing them in a tuple keeps the forward pass fully type-inferable (unlike a Chain).

DistilBERT.load_model — Function
load_model(source; init_random=false)
load_model(::Type{DistilBertForMaskedLM}, source; init_random=false)
load_model(::Type{DistilBertForSequenceClassification}, source; num_labels=2, init_random=false)
load_model(::Type{DistilBertForTokenClassification}, source; num_labels, init_random=false)
load_model(::Type{DistilBertForQuestionAnswering}, source; init_random=false)

Load a pre-trained DistilBERT model. source can be:

  • A local directory containing config.json + model.safetensors
  • A HuggingFace Hub model ID (e.g. "distilbert-base-uncased") — requires TransformersDownloads.jl to be in the active environment.

Weight format priority: SafeTensors > PyTorch .bin (Pickle).

Examples

# From a local directory:
model = load_model("models/distilbert-base-uncased")

# Directly from HuggingFace Hub (downloads and caches automatically):
model = load_model("distilbert-base-uncased")

# Sequence classification:
model = load_model(DistilBertForSequenceClassification, "distilbert-base-uncased"; num_labels=2)

DistilBERT.predict — Function
predict(model, tokenizer, text) -> AbstractArray{Float32,3}

Run inference on a single text string.

Note: Call Flux.testmode!(model) before inference to disable dropout. Call Flux.trainmode!(model) to re-enable it for training.

Arguments

  • model::DistilBertModel: The DistilBERT model
  • tokenizer::WordPieceTokenizer: The tokenizer

Returns

  • output::AbstractArray{Float32,3}: Hidden states of shape (dim, seqlen, 1). The output lives on the same device as the model parameters (CPU by default, GPU when the model was moved with `togpu`).

Example

Flux.testmode!(model)
output = predict(model, tokenizer, "Hello world!")

DistilBERT.unmask — Function
unmask(model, tokenizer, text; top_k=5) -> Vector{NamedTuple}

Predict the masked token(s) in a text, similar to HuggingFace's pipeline('fill-mask'). Alias for the fill-mask pipeline.

Note

Only the first [MASK] position is predicted. Split multi-mask texts into one unmask call per mask if you need all predictions.

Note: Call Flux.testmode!(model) before inference to disable dropout.

Arguments

  • model::DistilBertForMaskedLM: The masked language model
  • tokenizer::WordPieceTokenizer: The tokenizer
  • text::String: Input text containing [MASK] token(s)
  • top_k::Int: Number of top predictions to return per mask (default: 5)

Returns

  • Vector{NamedTuple}: Each entry has fields:
    • score::Float32: Probability of the predicted token
    • token::String: The predicted token
    • token_id::Int: The token ID
    • sequence::String: The full text with [MASK] replaced

Example

model = load_model(DistilBertForMaskedLM, "models/big")
tokenizer = WordPieceTokenizer("models/big/vocab.txt")
Flux.testmode!(model)

results = unmask(model, tokenizer, "Hello I'm a [MASK] model.")
for r in results
    println("$(r.score)  $(r.token)  =>  $(r.sequence)")
end

Supertype for pooling strategies accepted by embed:

Device & Precision

GPU support is backend-agnostic: the device layer works with any GPUArraysCore.AbstractGPUArray, and to_gpu uses Flux's active backend (CUDA by default; select AMDGPU/Metal with Flux.gpu_backend!). predict and embed automatically move inputs to the model's device.

DistilBERT.to_gpu — Function
to_gpu(model)

Move a model to the active GPU backend (CUDA, AMDGPU, or Metal).

Load the backend package and — if it is not CUDA, Flux's default — select it with Flux.gpu_backend!. Errors if no backend is active.

Only CUDA is covered by this package's test suite; other GPUArrays.jl backends are supported by construction but untested here.

Example

using CUDA, Flux
model = load_model("path/to/distilbert")
model_gpu = to_gpu(model)

# AMDGPU / Metal:
using AMDGPU, Flux
Flux.gpu_backend!("AMDGPU")   # takes effect after restarting Julia
model_gpu = to_gpu(model)

DistilBERT.to_bfloat16 — Function
to_bfloat16(model)

Convert model parameters to BFloat16 (Core.BFloat16, Julia ≥ 1.12).

BFloat16 has the same exponent range as Float32 (more numerically stable than Float16), supported on CUDA Ampere (30xx / A100) and newer hardware.

The conversion is device-preserving: conversion is done with broadcasting, so a GPU array stays on the GPU.

DistilBERT.prepare_inputs — Function
prepare_inputs(input_ids, attention_mask=nothing) -> (Matrix{Int32}, Matrix{Float32}|Nothing)

Normalize input types for CPU inference:

  • input_ids is converted to Int32 (matches GPU conventions, avoids type mismatch).
  • attention_mask is converted to Float32 if provided.

For GPU inference, predict/embed transfer inputs to the model's device automatically. To move arrays manually, use CuArray{Int32}(ids) / CuArray{Float32}(mask) (or the equivalent for your backend).

Example

ids, mask = prepare_inputs(raw_ids, raw_mask)
output = model(ids; mask=mask)
